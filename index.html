2例题 · 放弃期权（Abandonment Option）

例 题
预期新项目未来 10年 每年售出 6000单位 产品，每单位带来 50美元 净现金流，折现率 16%，初始投资 120万美元。
  1. (1)基本情况下的 NPV？
  2. (2)第1年后可100万卖出，何时放弃合理？
  3. (3)50/50成败概率下，含放弃期权 NPV 与期权价值？
关键条件：无论如何，第1年的销售量都能达到6000单位（即 t=1 CF 确定）
1 基本情况下的 NPV BASE CASE
①
年现金流 = 6000 × 50 = 30万；查表 \( \text{PVIFA}(16\%,10) = 4.833 \)
②
\[ \text{NPV} = -120 + 30 \times 4.833 = -120 + 145 = 25 \text{ 万} \]
③
NPV = +25万 > 0，应投资 ✓
2 放弃临界销售量 BREAKEVEN
第1年末比较 — 继续经营9年的PV vs 立刻放弃得100万，哪个更划算。
①
放弃条件：\( CF \times \text{PVIFA}(16\%,9) < 100 \)，其中 \( \text{PVIFA}(16\%,9)=4.607 \)
②
\[ 50Q \times 4.607 < 100\text{万} \;\Rightarrow\; Q < \frac{1{,}000{,}000}{50 \times 4.607} = 4341.65 \]
③
当年销低于 ≈ 4342 单位 时，应在第1年末放弃、出售得100万。
3 含放弃期权的 NPV 与期权价值 OPTION VALUE
失败时年销 4000 < 4342 → 应放弃。注意题目说"无论如何 t=1 都收 30 万"——不确定性只在 t=2~10。
t=0         t=1（确定收30万，再决策）          t=2 ~ t=10
                    ┌─ 成功(50%) →  继续  →    每年 30 万
-120万 ── 30万 ────┤
                    └─ 失败(50%) →  放弃  →    清算 100 万

各部分 PV（折回 t=0）

①
t=1 确定 CF：\( \dfrac{30}{1.16} = 25.86 \) 万
②
成功路径 t=2~10（×50%）：\( 0.5 \times \dfrac{30 \times 4.607}{1.16} = 0.5 \times 119.15 = 59.57 \) 万
③
失败放弃清算（×50%）：\( 0.5 \times \dfrac{100}{1.16} = 0.5 \times 86.21 = 43.10 \) 万

含期权 NPV

\[ \text{NPV}_{\text{含期权}} = -120 + 25.86 + 59.57 + 43.10 \;=\; \mathbf{8.53\text{ 万}} \]

对照：不含期权 NPV（失败时硬扛9年20万）

\[ \text{NPV}_{\text{无期权}} = -120 + 25.86 + 59.57 + \underbrace{0.5 \times \tfrac{20\times 4.607}{1.16}}_{39.72} \;=\; \mathbf{5.14\text{ 万}} \]

期权价值

8.53 − 5.14 = 3.39 万 期权只在失败时发挥作用

0股票估值模型选择总表

题目特征 优先模型 核心公式 拿分动作
股利固定不变 固定股利模型 \(P_0=\dfrac{D_1}{r_s}\) 确认是永续固定股利，直接按永续年金定价。
股利固定增长 戈登增长模型 \(P_0=\dfrac{D_1}{r_s-g}\) 先判断题目给的是 \(D_0\) 还是 \(D_1\)，若给 \(D_0\)，先乘 \(1+g\)。
增长分阶段变化 两阶段 DDM \(P_0=\sum\dfrac{D_t}{(1+r_s)^t}+\dfrac{P_n}{(1+r_s)^n}\) 先画时间轴：前期逐年折现，稳定期用戈登公式算终值。
题目强调盈利、留存、ROE NPVGO \(V_0=\dfrac{E_1}{r_s}+NPVGO\) 判断 \(ROE\) 与 \(r_s\)：只有 \(ROE>r_s\)，留存才创造股东财富。
题目给 PE / EPS / 同行业倍数 相对估值 PE \(PE=\dfrac{P}{EPS}\)，\(\dfrac{1}{PE}=\dfrac{EPS}{P}\) 先确认盈利口径：历史 \(E_0\)、预期 \(E_1\)、还是 TTM。
拿分结论：股票估值题不要先背公式，要先识别现金流形态。股利题用 DDM，盈利与留存题用 NPVGO，倍数题用 PE；再检查时点和增长率是否匹配。
高频易错：\(D_0\) 是刚发的股利，不能直接放进戈登公式；\(D_1\) 才是下一期股利。\(E_0\) 是历史 EPS，\(E_1\) 是预期 EPS，PE 口径不同，数值就会不同。

1股票基础知识

（1）含义：投资者对公司的股权投资

（2）股东权益（重要）：剩余索取权 · 剩余控制权 · 优先认股权

（3）种类

● 普通股：最终的剩余索取权、剩余控制权

A. 简单多数投票制：每股1票，对每名董事候选人分别投票

选出1名董事所需股数 = \(\tfrac{1}{2}\times\) 总股数 \(+1\)　→ 大股东控制董事会

B. 累计投票制：选N名董事时每股有N票，对所有候选人同时投票

选出1名董事所需股数 = \(\tfrac{1}{N+1}\times\) 总股数 \(+1\)　→ 对中小股东友好（更公平）

推导：设持股比例为 \(x\)，集中全票只投1人，需超过对手每人最多得票：

\[\underbrace{x \cdot N}_{\text{自己集中票数}} \;>\; \underbrace{\frac{(1-x)\cdot N}{N}}_{\text{对手每人最多票}} = 1-x \;\Rightarrow\; xN+x > 1 \;\Rightarrow\; x > \frac{1}{N+1}\]

● 优先股：剩余索取权在普通股股东之前，通常没有剩余控制权

2绝对估值模型——股利贴现模型（DDM）

A. 含义与公式

股票的内在价值（\(V_0\)）= 未来所有股利的现值之和：

\[V_0(P_0) = \frac{D_1}{1+r_s} + \frac{D_2}{(1+r_s)^2} + \cdots = \sum_{t=1}^{\infty} \frac{D_t}{(1+r_s)^t}\]
横截性条件（无泡沫条件）：\(\displaystyle\lim_{n\to\infty}\dfrac{V_n}{(1+r_s)^n}=0\)
含义：股价不能永远上涨——若远期股价增速持续超过折现率 \(r_s\)，现值发散至无穷大，公式无意义。这是上式成立的前提条件。

递推关系：

\[V_0 = \frac{D_1}{1+r_s}+\frac{V_1}{1+r_s},\quad V_1 = \frac{D_2}{1+r_s}+\frac{V_2}{1+r_s},\quad \cdots\]

股价决定链条：

投资决策 → Sales ↑ → 净利润 \(E_t\) ↑ → 股利 \(D_t\) ↑ → \(V_0\) ↑ （股利由净利润决定）

B. 三种子模型

公司阶段模型名称适用条件定价公式
成熟期 固定股利模型 每期股利不变（永续年金） \(P_0 = \dfrac{D_1}{r_s}\)
成长期 固定股利增长模型
（戈登增长模型） ★★ 		股利以固定增长率 \(g\) 永续增长（要求 \(r_s > g\)） \(P_0 = \dfrac{D_1}{r_s - g}\)
其中 \(D_1 = D_0(1+g)\)
初创期 不规则增长模型
（两阶段模型）		 增长率分阶段变动 \(P_0 = \displaystyle\sum_{t=1}^{n}\dfrac{D_t}{(1+r_s)^t}+\dfrac{V_n}{(1+r_s)^n}\)
其中 \(V_n = \dfrac{D_{n+1}}{r_s-g_2}\)

C. 戈登增长模型参数拆解 ★

$P_0=\dfrac{D_1}{r_s-g}$ 中三个参数各自如何确定：

a
股利 $D_1$：
\[D_1 = EPS_1 \times (1-b)\]
留存比率 $b$ = 留存收益／净利润；股利支付率 $(1-b)$ = 股利／净利润
即 D/EPS = 1−b，已知 EPS 和留存比率即可算出 $D_1$
b
增长率 $g = ROE \times b$（考试直接用简化版）

逻辑链（从源头理解）：

EPS 的 $b$ 比例留存 → 以 ROE 投资 → 权益增长率 = $ROE \times b$ → D/EPS 不变 ∴ 股利同速增长

推导：$\dfrac{\Delta S}{S_0}=\dfrac{NI\times b}{S_0}=ROE\times b$，故

\[\boxed{g = ROE \times b} \quad \text{（股利增长率 = 利润增长率 = 权益增长率）}\]
更精确版（考虑复利，用下期ROE）：$g=ROE\times(1+g)\times b \;\Rightarrow\; g=\dfrac{ROE\cdot b}{1-ROE\cdot b}$
⚠️ 此处 ROE 定义为新增投入资本的回报率，与财务报表中的 ROE 含义不同
c
折现率 $r_s$：外生（由市场决定，1964年后用 CAPM）

【补充】由戈登公式反推 $r_s$ 的分解：

\[P_0=\frac{D_1}{r_s-g} \;\Rightarrow\; r_s = \underbrace{\frac{D_1}{P_0}}_{\text{股利收益率}} + \underbrace{g}_{\text{资本利得率}}\]
关键推论：在戈登增长模型下，资本利得率 = 股利增长率 $g$
证明：\(\dfrac{P_1-P_0}{P_0}=\dfrac{\frac{D_2}{r_s-g}-\frac{D_1}{r_s-g}}{\frac{D_1}{r_s-g}}=\dfrac{D_2-D_1}{D_1}=g\;\checkmark\)
→ 在戈登模型下，资本利得率就是股利增长率

3例题：两阶段增长模型（DG公司）

例 题
DG公司今年发放每股 D₀=1美元 红利，预计未来 3年 红利每年增长 25%，之后增长率降至 5% 并永续，折现率 r_s=20%。
  1. (1)股票内在价值 \(V_0\) 为多少？
  2. (2)若市价 = 内在价值，股利收益率？
  3. (3)投资者预计一年后价格 \(V_1\)？
模型：两阶段 DDM
关键：\(V_n\) 在第 n 期末用戈登公式定价，再折回 \(t=0\)

现金流时间轴

1 内在价值 \(V_0\) TWO-STAGE DDM
先算高增长期各期股利，再用戈登公式算第3年末终值 \(V_3\)，全部折回 \(t=0\)。
①
各期股利：\(D_1=1\times1.25=1.25,\; D_2=1.25^2=1.5625,\; D_3=1.25^3=1.953,\; D_4=D_3\times1.05=2.051\)
②
第3年末终值（g₂=5%永续）：
\[V_3 = \frac{D_4}{r_s - g_2} = \frac{2.051}{0.20-0.05} = \frac{2.051}{0.15} = 13.67\]
③
代入两阶段公式 \(\;P_0=\displaystyle\sum_{t=1}^{3}\dfrac{D_t}{(1+r_s)^t}+\dfrac{V_3}{(1+r_s)^3}\)，其中终值折现项可合并写成：
\[\frac{V_3}{(1+r_s)^3} = \frac{D_4}{(r_s-g_2)(1+r_s)^3} = \frac{1.25^3\times1.05}{(0.2-0.05)\times(1+0.2)^3} = \frac{2.051}{0.15\times1.728} = 7.91\]
因此：
\[V_0 = \underbrace{\frac{1.25}{1.2}+\frac{1.5625}{1.2^2}+\frac{1.953}{1.2^3}}_{\displaystyle=1.04+1.09+1.13\;=\;3.26} + \underbrace{\frac{1.25^3\times1.05}{(0.2-0.05)\times1.2^3}}_{\displaystyle=7.91} = \mathbf{11.17 \text{ 美元}}\]
V₀ = 11.17 美元 ✓
2 股利收益率 DIVIDEND YIELD
①
市价 = 内在价值 = 11.17，下一期股利 \(D_1=1.25\)
\[\text{股利收益率} = \frac{D_1}{P_0} = \frac{1.25}{11.17} \approx \mathbf{11.19\%}\]
股利收益率 ≈ 11.19%
3 一年后价格 \(V_1\) HOLDING PERIOD
利用DDM递推：今天总回报 = 下期股利 + 下期价格，折现后等于今天股价。

法1（DDM递推）：

①
由 \(V_0 = \dfrac{D_1 + V_1}{1+r_s}\) 整理得：
\[V_1 = V_0\times(1+r_s) - D_1 = 11.17\times1.2 - 1.25 = 13.40-1.25 = \mathbf{12.15 \text{ 美元}}\]
V₁ = 12.15 美元 ✓

法2（利用总回报率分解 \(r_s\) = 股利收益率 + 资本利得率）：

①
由（2）已知股利收益率 = 11.19%，而折现率 \(r_s=20\%\)，二者之差即为资本利得率：
\[\text{资本利得率} = r_s - \frac{D_1}{V_0} = 20\% - 11.19\% = 8.81\%\]
②
资本利得率即股价涨幅，故一年后股价：
\[V_1 = V_0\times(1+8.81\%) = 11.17\times1.0881 \approx \mathbf{12.15 \text{ 美元}}\]
V₁ = 12.15 美元 ✓
⚠️ 重要区分——戈登模型 vs 本题
戈登增长模型（固定股利增长模型）是一阶段模型：股利以固定增长率 \(g\) 永续增长，此时可推导出"资本利得率 = \(g\)"。
本题是两阶段模型，当前处于高增长期（\(g_1=25\%\)），并非永续增长，戈登模型不适用，因此资本利得率（8.81%）既不等于 \(g_1=25\%\)，也不等于 \(g_2=5\%\)。
法2所用的是更一般的恒等式：\(r_s = \text{股利收益率} + \text{资本利得率}\)，该式在任何 DDM 框架下均成立，与是否为戈登模型无关。

4NPVGO — 成长机会净现值

A. 核心公式

将股票价值拆成两部分：

\[V_0 = \underbrace{\frac{E_1}{r_s}}_{\text{现金牛价值}} + \underbrace{NPVGO}_{\text{增长机会净现值}}\]

现金牛公司（Cash Cow）：$b=0$，即所有利润都发放为股利，不做任何再投资。 此时 $g = ROE \times b = 0$，股价退化为永续年金：$P_0 = \dfrac{E_1}{r_s}$

$E_1/r_s$ 是一条基准线——"如果公司什么增长机会都不追求，股票值多少钱"。
$NPVGO$ 则衡量：公司选择留存再投资，相比这条基准线，到底是创造了价值还是摧毁了价值。

B. 辨析：留存 ≠ 价值增加

条件NPVGO股价结论
$ROE > r_s$$> 0$↑ 高于现金牛应该投资，增长创造价值
$ROE = r_s$$= 0$= 现金牛无差异，投不投一样
$ROE < r_s$$< 0$↓ 低于现金牛不应投资，增长摧毁价值

⚠️ 只要 $ROE > 0$，增加留存就能让利润和股利增速加快——但这不代表股价一定上升。只有 $ROE > r_s$ 时，留存才真正增加股东财富。

C. $g = ROE \times b$ 的推导（DuPont 传导链）

核心问题：把利润的 $b$ 比例留下来再投资，下一期净利润会增长多少？

核心假设：新投入资本的盈利能力与现有资产相同（即边际 $ROE$ = 平均 $ROE$）。正是这个假设让整个链条得以化简为一个乘积。
①
留存 → 新增权益
\[\Delta S = NI_0 \times b\]

公司把 $b$ 比例的利润不分红，存入公司账上 → 股东权益净增加 $\Delta S$

②
新增权益 → 新增总资产（乘以 $EM$）
\[\Delta A = \Delta S \times EM, \quad EM = \frac{\text{总资产}}{\text{权益}}\]

公司的资产负债结构（杠杆比）维持不变。权益多了 $\Delta S$，银行按同样比例多借钱，总资产随之增加 $\Delta S \times EM$

③
新增资产 → 新增销售额（乘以 $ATO$）
\[\Delta Sales = \Delta A \times ATO, \quad ATO = \frac{\text{销售额}}{\text{总资产}}\]

新增的资产投入运营，按同样的资产使用效率（每元资产能创造多少销售额），带来相应的新增收入

④
新增销售额 → 新增净利润（乘以 $PM$）
\[\Delta NI_1 = \Delta Sales \times PM, \quad PM = \frac{\text{净利润}}{\text{销售额}}\]

新增收入按同样的成本结构和税率（利润率），最终变成净利润

⑤
合并四步（$ROE = PM \times ATO \times EM$，即 DuPont 公式）
\[\Delta NI_1 = NI_0 \times b \times \underbrace{EM \times ATO \times PM}_{ROE}\]
\[\therefore\; g = \frac{NI_1 - NI_0}{NI_0} = \frac{\Delta NI_1}{NI_0} = \boxed{ROE \times b}\]

四个步骤的乘积恰好就是 $ROE$ 的 DuPont 拆解，所以最终化简为 $g = ROE \times b$

D. 两类 NPVGO 计算场景

根据投资机会的持续性，计算路径有所不同：

类型 适用场景 计算路径
持续性增长
永续再投资		 公司以固定留存比例 \(b\) 持续投资，增长率 \(g\) 恒定 ① 直接用戈登模型：\(P_0 = \dfrac{D_1}{r_s - ROE \cdot b}\)
② 反推：\(NPVGO = P_0 - \dfrac{E_1}{r_s}\)
一次性项目
有限期投资		 在某一时点投入资金，项目存续有限年，之后恢复零增长 ① 先算项目 NPV（折现到投资时点）
② \(NPVGO = \dfrac{NPV_\text{项目}}{(1+r_s)^t}\)（再折回 \(t=0\)）
③ \(P_0 = \dfrac{E_1}{r_s} + NPVGO\)

5例题：Lane Supermarkets（NPVGO 完整应用）

例 题
Lane Supermarkets 共发行 1万股，每年净利润 10万元，折现率 $r_s=16\%$。两种方案：

方案①（现金牛）：所有利润作为股利发放，不再投资

方案②（拓展）：每年留存 $b=20\%$，投资 $ROE=10\%$ 的项目（第一年利润仍 10 万，第二年起变动）
  1. (1)方案②下利润和股利的增长率 $g$？
  2. (2)两种方案下每股股价？
  3. (3)NPVGO 是多少？公司是否应该选择投资？
1 增长率 $g$
\[g = ROE \times b = 10\% \times 20\% = 2\%\]
g = 2%
2 两种方案下每股股价
①
每股利润：$EPS_1 = 10\text{万} \div 1\text{万股} = 10\text{ 元}$
②
方案①（现金牛，$b=0$，$g=0$）：
\[P_0 = \frac{E_1}{r_s} = \frac{10}{16\%} = 62.5\text{ 元}\]
现金牛股价 = 62.5元
③
方案②（拓展投资）：
\[P_0 = \frac{D_1}{r_s - g} = \frac{E_1(1-b)}{r_s - ROE\times b} = \frac{10\times(1-20\%)}{16\%-2\%} = \frac{8}{0.14} \approx 57.14\text{ 元}\]
拓展股价 = 57.14元 < 62.5元
3 NPVGO 与投资决策
①
由 $V_0 = E_1/r_s + NPVGO$，反推 NPVGO：
\[NPVGO = P_0^{②} - \frac{E_1}{r_s} = 57.14 - 62.5 = \mathbf{-5.36\text{ 元}} < 0\]
②
结论：不应选择投资

$ROE(10\%) < r_s(16\%)$：公司把钱留下来投项目，每一元只能赚 10 分，但市场要求回报是 16 分。留存再投资相当于在"做亏本买卖"，每股摧毁了 5.36 元的价值。

6例题：Stambaugh 公司（有限期项目 NPVGO）

例 题
Stambaugh 公司当前每股盈利 $E_0 = 8.25$ 美元，增长率为零，所有盈利均作为股利发放。现有一项新机会：1年后需投资 每股 1.60 美元，该项目仅持续两年，将使投资完成后两年内每股盈利分别上升 2.10 美元 和 2.45 美元，之后恢复原水平。投资者要求回报率 $r_s = 12\%$。
  1. (1)不进行投资时，公司每股价值是多少？
  2. (2)进行投资后，公司每股价值是多少？
  3. (3)进行投资后，\(t=4\) 时的股价是多少？
1不投资时的每股价值

零增长永续年金，直接套公式：

\[V_0 = \frac{E_1}{r_s} = \frac{8.25}{12\%} = \mathbf{68.75 \text{ 美元}}\]
现金牛基准价 = 68.75 美元
2投资后的每股价值

项目是一次性，用"折现项目 NPV"法：

①
在 \(t=1\) 时点计算项目 NPV（投资发生在 \(t=1\)，收益在 \(t=2, 3\)）：
\[NPV_1 = -1.60 + \frac{2.10}{1.12} + \frac{2.45}{1.12^2} = -1.60 + 1.875 + 1.953 \approx 2.23\text{ 美元}\]
②
将项目 NPV 折回 \(t=0\) 得 NPVGO：
\[NPVGO = \frac{NPV_1}{1+r_s} = \frac{2.23}{1.12} \approx \mathbf{1.99\text{ 美元}}\]
③
加回现金牛基准价：
\[V_0 = \frac{E_1}{r_s} + NPVGO = 68.75 + 1.99 \approx \mathbf{70.74\text{ 美元}}\]
投资后每股价值 = 70.74 美元
3\(t=4\) 时的股价 \(P_4\)

项目的效益在 \(t=2,3\) 已兑现，\(t=4\) 起盈利恢复为 8.25 美元的永续零增长。 站在 \(t=4\) 看，未来股利流 \(= 8.25, 8.25, \ldots\)，故：

\[P_4 = \frac{E_5}{r_s} = \frac{8.25}{12\%} = \mathbf{68.75\text{ 美元}}\]
注意 \(P_4 = 68.75 < V_0 = 70.74\)。这并不矛盾：\(V_0\) 之所以更高，是因为它在 \(t=0\) 已经包含了对未来两年超额收益的预期（NPVGO）；到了 \(t=4\) 项目效益已全部兑现，股价自然回落到现金牛水平。

7相对估值模型——市盈率（PE）

A. 定义：每 1 元盈利对应多少价格

市盈率（PE, Price-to-Earnings Ratio）属于相对估值模型 / 乘数法，衡量投资者愿意为公司“每 1 元每股盈利”支付多少价格。

\[PE = \frac{P}{EPS}\]

其中 \(P\) 是每股市场价格，\(EPS\) 是每股收益。PE 本质上是一个“价格 / 盈利”的倍数。

PE 的倒数是盈利收益率（Earnings Yield）：
\[\frac{1}{PE}=\frac{EPS}{P}\]
含义是每花 1 元买股票，对应能获得多少元每股盈利。例如 \(PE=20\)，则盈利收益率 \(=1/20=5\%\)，常用来和债券收益率、无风险利率比较。

B. 三种盈利口径：\(E_0\)、\(E_1\)、TTM

口径公式含义
历史市盈率
静态 PE		 \(\displaystyle \frac{P_0}{E_0}\) \(E_0\) 是上一期已经披露的年度每股盈利，例如 2025 年报 EPS。
预期市盈率
动态 PE / Forward PE		 \(\displaystyle \frac{P_0}{E_1}\) \(E_1\) 是下一期预期每股盈利，例如 2026 年预期 EPS。
滚动市盈率
TTM PE		 \(\displaystyle \frac{P_0}{E_{\text{TTM}}}\) \(E_{\text{TTM}}\) 是最近 4 个季度 EPS 之和，即最近 12 个月盈利。
现实中同一家公司会出现多个 PE，核心原因是分母的盈利口径不同：年报用 \(E_0\)，预测用 \(E_1\)，实时估值常用最近 4 个季度的 TTM EPS。

C. 用戈登增长模型推导 PE

从戈登增长模型出发：

\[P_0 = \frac{D_1}{r_s-g}\]

股利可以拆成“每股盈利 × 股利支付率”：

\[D_1 = E_1 \times d = E_1(1-b)\]

其中 \(d\) 是股利支付率，\(b\) 是留存比率，且 \(d = 1-b\)。

①
代回戈登模型：
\[P_0 = \frac{E_1(1-b)}{r_s-g}\]
②
两边同时除以 \(E_1\)，得到预期市盈率：
\[\frac{P_0}{E_1} = \frac{1-b}{r_s-g}\]
Forward PE = \(\frac{1-b}{r_s-g}\)
③
若分母用历史盈利 \(E_0\)，且 \(E_1 = E_0(1+g)\)，则：
\[\frac{P_0}{E_0} = \frac{(1-b)(1+g)}{r_s-g}\]
Trailing PE = \(\frac{(1-b)(1+g)}{r_s-g}\)

D. 市盈率的影响因素

因素方向逻辑
增长机会
最主要因素		 \(g \uparrow \Rightarrow PE \uparrow\) 增长机会越多，未来盈利增长越强，\(r_s-g\) 变小，市场愿意给更高估值倍数。
风险 \(r_s \uparrow \Rightarrow PE \downarrow\) 风险越高，未来盈利不确定性越高，投资者愿意支付的当期股价 \(P_0\) 下降，因此 PE 下降。
无风险利率 \(r_f \uparrow \Rightarrow r_s \uparrow \Rightarrow PE \downarrow\) 利率上升会推高股东必要报酬率，股票估值倍数通常下降。
会计方法 \(EPS \downarrow \Rightarrow PE \uparrow\) 会计方法越保守，当期确认利润越低；若股价不变，账面 PE 会被动升高。反过来，会计政策越激进，当期利润 \(E\) 可能被做高，PE 会被动下降。
PE 高的公司通常被称为成长型公司，因为市场预期其未来增长机会多；PE 低的公司通常被称为价值型公司，但低 PE 不一定等于便宜，也可能反映增长机会少或风险较高。

E. 会计政策为什么会影响 PE：存货计价例子

会计政策会影响分母 \(E\)（EPS / 每股盈利）。利润不是纯粹“自然发生”的数字，它会受到收入确认、费用确认、折旧摊销、存货计价等会计处理影响。

核心链条：会计政策 → 成本/费用确认 → 净利润 \(E\) → \(PE=\dfrac{P}{E}\)。如果 \(P\) 暂时不变，利润 \(E\) 被做高，PE 会下降；利润 \(E\) 被压低，PE 会上升。
术语注释
FIFO
先进先出		 First-In, First-Out：先买进的存货先被假定卖出。价格上升时，先卖出低成本老存货。
LIFO
后进先出		 Last-In, First-Out：后买进的存货先被假定卖出。价格上升时，先卖出高成本新存货。
COGS
销售成本		 Cost of Goods Sold：卖出去的商品对应的成本。COGS 越高，毛利和净利润越低。
存货 还没卖出去、留在资产负债表里的商品成本，属于资产。
原材料 / 商品采购 → 进入存货 → 卖出部分转为 COGS → 没卖出的留在存货
价格上升时COGS（销售成本）净利润 \(E\)期末存货 / 总资产
FIFO 先进先出 低：先卖低成本老存货 高：成本低，所以利润高 高：剩下的是高成本新存货
LIFO 后进先出 高：先卖高成本新存货 低：成本高，所以利润低 低：剩下的是低成本老存货
老师笔记结论：价格上涨时，LIFO（后进先出）利润更低、资产更低，表现更保守；FIFO（先进先出）利润更高、资产更高，报表看起来更“好看”。所以会计政策激进会让 \(E\) 偏高，进而使 \(P/E\) 看起来偏低。

F. 市盈率估值法：怎么用 PE 给目标公司估价

①
找可比公司：同行业、商业模式相似、增长阶段接近、风险水平接近、盈利口径一致。
②
算可比公司的 PE：
\[PE_{\text{可比}}=\frac{P_{\text{可比}}}{EPS_{\text{可比}}}\]
③
估目标公司股价：
\[P_{\text{目标}}=PE_{\text{可比}}\times EPS_{\text{目标}}\]
可比公司难点：增长率、风险、资本结构、会计政策、盈利周期不同，都会让 PE 不可比。相对估值法好用，但最怕“看起来像可比，实际不可比”。

G. 为什么资本结构差异大时用 EV/EBITDA

PE 的分子是股权价值 \(P\)，分母是股东口径的净利润 \(E\)。如果两家公司债务比例、利息费用、税率、折旧政策差异很大，PE 可能比较失真。

\[EV = \text{权益市值} + \text{有息债务市值} - \text{现金及等价物}\]
项目PEEV/EBITDA
分子 \(P\)：只看股权价值 \(EV\)：看公司整体价值，把股权和有息债务都纳入，再扣除现金
资本结构 受影响。债务多会带来利息费用，影响净利润 \(E\) 更可比。EV 把债务纳入企业整体价值，EBITDA 在利息前，弱化融资结构差异
会计政策 受影响。折旧、摊销、存货计价会影响净利润 部分弱化。EBITDA 是息税折旧摊销前利润，剔除了折旧摊销差异
税收差异 受影响。净利润是税后利润，不同税率会直接影响 \(E\) 不直接受影响。EBITDA 在所得税之前，税率差异不直接进入分母
拿分结论：EV/EBITDA 适合比较资本结构、税收待遇、折旧摊销政策差异较大的公司。它不是完美指标，但比 PE 更接近“公司整体经营业务价值”的比较。

H. 例题：股利支付率变化与股票价格

例 题
已知某公司股票当前每股收益为 \(E_0=1\) 元，当前市场价格为每股 10元（假设均衡定价），股利支付率 \(d=50\%\)，剩余资金投资于 \(ROE=10\%\) 的项目，求：
  1. (1)股票必要报酬率 \(r_s\)
  2. (2)现金牛状态下，不投资项目，股票价格
  3. (3)若股利支付率降低到 30%，股票价格
核心：股利支付率下降，会同时降低 \(D_1\)、提高留存比率 \(b\)，进而改变增长率 \(g=ROE\times b\)。
1 求必要报酬率 \(r_s\)
①
当前股利支付率 \(d=50\%\)，所以留存比率 \(b=50\%\)，增长率：
\[g = ROE \times b = 10\% \times 50\% = 5\%\]
②
下一期盈利与股利：
\[E_1 = E_0(1+g)=1\times1.05=1.05,\qquad D_1=E_1\times d=1.05\times50\%=0.525\]
③
由 \(P_0=\dfrac{D_1}{r_s-g}\) 反推：
\[10=\frac{0.525}{r_s-5\%}\Rightarrow r_s-5\%=5.25\%\Rightarrow \boxed{r_s=10.25\%}\]
rₛ = 10.25%
2 现金牛状态下的股价
现金牛状态表示不再投资，\(b=0\)，\(d=100\%\)，\(g=0\)，全部盈利作为股利发放。
\[P_0=\frac{D_1}{r_s}=\frac{1}{10.25\%}\approx \mathbf{9.76\text{ 元}}\]

原股价 10 元高于现金牛价值 9.76 元，说明原来的增长机会有正价值： NPVGO = 10 − 9.76 = 0.24元

3 股利支付率降至 30% 后的股价
①
新的留存比率 \(b=70\%\)，增长率：
\[g=ROE\times b=10\%\times70\%=7\%\]
②
下一期盈利与股利：
\[E_1=E_0(1+g)=1.07,\qquad D_1=E_1\times d=1.07\times30\%=0.321\]
③
代入戈登公式：
\[P_0=\frac{0.321}{10.25\%-7\%}=\frac{0.321}{3.25\%}\approx \mathbf{9.88\text{ 元}}\]
P₀ ≈ 9.88元
股利支付率下降有两股相反力量：一方面 \(d\downarrow\) 使 \(D_1\downarrow\)，压低股价；另一方面 \(b\uparrow\) 使 \(g=ROE\times b\uparrow\)，抬高未来增长。最终结果取决于项目 \(ROE\) 与股东必要报酬率 \(r_s\) 的关系。本题中 \(ROE=10\% < r_s=10.25\%\)，提高留存比例并不会创造更多价值，反而使股价从 10 元降至约 9.88 元。
PE 易错点：PE 高不等于一定贵，PE 低也不等于一定便宜。先看增长机会、风险、利率和盈利口径；尤其要分清 \(P_0/E_0\)、\(P_0/E_1\)、\(P_0/E_{\text{TTM}}\)。
拿分结论：考试中看到 PE，先确认分母 EPS 口径，再判断增长机会和风险。增长机会是最主要因素；风险越高，未来盈利不确定性越高，当期股价和 PE 通常下降。

2 会计政策——FIFO 与 LIFO 对利润和资产的影响 2025 · 清华
选 择 题
当价格水平上升时，与采用后进先出的公司相比，先进先出的公司的财务报表（ ）
A. 总资产和净利润都低B. 总资产和净利润都高 C. 总资产低，净利润高D. 总资产高，净利润高 ✓
先记住存货流转：采购进入存货；卖出去的部分转成 COGS（销售成本）；没卖出去的继续留在资产负债表的存货里。
①

3 低 PE 的解释——哪一个最不可能成立 2020 · 人大
选 择 题
2019年1月2日至今，上市公司中国工商银行的股票市盈率一直处于较低水平，在 A 股市场上市公司处于相对较低水平，以下解释最不可能成立的是（ ）
A. 会计政策激进B. 增长机会少 C. 较低的 \(r_s\) ✓D. 贷款风险高
①
增长机会少可以解释低 PE：
\[g \downarrow \Rightarrow r_s-g \uparrow \Rightarrow PE \downarrow\]
②
贷款风险高也可以解释低 PE：
\[\text{风险高} \Rightarrow r_s \uparrow \Rightarrow PE \downarrow\]
③
会计政策激进为什么也可能解释低 PE：激进政策可能提前确认收入、推迟确认费用，或采用让当期成本更低的处理方式，使当期利润 \(E\) 偏高。

④

4 EV/EBITDA 与税收差异 2020 · 人大 / 2021 · 人大
判 断 题
运用企业价值（EV）乘数估计公司整体业务价值时，不同公司所得税待遇方面存在的差异不会对该乘数产生直接影响。（ ）
这里说的是 EV/EBITDA 这类企业价值乘数。EBITDA 是 Earnings Before Interest, Taxes, Depreciation and Amortization，即息税折旧摊销前利润。
①
EV/EBITDA 的分母在所得税之前：
\[EBITDA = \text{税前、利息前、折旧摊销前的经营利润}\]
所得税待遇差异不会直接进入 EBITDA，所以题干说法成立。
②
对比 PE：PE 的分母是净利润 \(E\)，净利润是税后利润，因此税率不同会直接影响 PE。
\[\text{税率差异} \Rightarrow E_{\text{税后}} \text{不同} \Rightarrow P/E \text{受影响}\]
判断：正确
拿分结论：EV/EBITDA 弱化了资本结构、税收待遇、折旧摊销会计政策的影响；PE 则会受到利息、所得税和会计利润口径影响。

10 NPVGO — ROE 与必要回报率的关系对留存决策的影响 2022 · 中财
计 算 题
股东必要回报率 $r_s = 10\%$，公司永续盈利 $E = 10$ 元/股，增长率为零。现有一投资机会：第一年不发放股利（全部留存投资），第二年起将全部盈利作为股利发放（\(D_2 = E_2\)）。

（1）若 \(ROE = 5\%\)，求 NPVGO 与股票估值；
（2）若 \(ROE = 20\%\)，求 NPVGO 与股票估值；
（3）结合（1）与（2），分析 ROE 与股东必要回报率之间的关系如何影响留存对股价的作用？

（1）ROE = 5%

①
\(t=1\) 投入 10 元，每年新增盈利 \(= 10 \times 5\% = 0.5\) 元（永续，从 \(t=2\) 起）。 在 \(t=1\) 时点计算项目 NPV：
\[NPV_1 = -10 + \frac{0.5}{10\%} = -10 + 5 = -5\text{ 元}\]
②
折回 \(t=0\)：
\[NPVGO = \frac{-5}{1+10\%} = \frac{-5}{1.1} \approx \mathbf{-4.55\text{ 元}}\]
③
\[V_0 = \frac{E_1}{r_s} + NPVGO = \frac{10}{10\%} + (-4.55) = 100 - 4.55 = \mathbf{95.45\text{ 元}}\]
NPVGO = −4.55 元，V₀ = 95.45 元（投资摧毁价值）

（2）ROE = 20%

①
每年新增盈利 \(= 10 \times 20\% = 2\) 元（永续，从 \(t=2\) 起）。 在 \(t=1\) 时点计算项目 NPV：
\[NPV_1 = -10 + \frac{2}{10\%} = -10 + 20 = 10\text{ 元}\]
②
折回 \(t=0\)：
\[NPVGO = \frac{10}{1+10\%} = \frac{10}{1.1} \approx \mathbf{9.09\text{ 元}}\]
③
\[V_0 = \frac{E_1}{r_s} + NPVGO = \frac{10}{10\%} + 9.09 = 100 + 9.09 = \mathbf{109.09\text{ 元}}\]
NPVGO = 9.09 元，V₀ = 109.09 元（投资创造价值）

（3）结论

留存再投资对股价的影响，完全取决于 ROE 与 \(r_s\) 的大小关系：
  • \(ROE < r_s\)（5% < 10%）：留存收益的回报率低于股东要求回报率，每留存 1 元只能赚 0.05 元而非 0.10 元，NPVGO < 0，留存摧毁股东财富
  • \(ROE > r_s\)（20% > 10%）：留存收益创造的回报超过股东机会成本，NPVGO > 0，留存增加股东财富
类比资本预算：留存相当于公司在替股东做投资，只有 IRR（即 ROE）> 必要回报率时，这笔投资才是正 NPV 的。

9考前速记 · 股票估值

A. 必背公式

公式使用场景检查点
\(P_0=\dfrac{D_1}{r_s}\) 固定股利 / 零增长 \(D_1\) 是未来每期固定股利。
\(P_0=\dfrac{D_1}{r_s-g}\) 固定股利增长 必须满足 \(r_s>g\)，且 \(D_1=D_0(1+g)\)。
\(P_0=\sum\dfrac{D_t}{(1+r_s)^t}+\dfrac{P_n}{(1+r_s)^n}\) 两阶段 / 不规则增长 \(P_n\) 站在第 \(n\) 年末，用下一期股利定价。
\(V_0=\dfrac{E_1}{r_s}+NPVGO\) 盈利、留存、ROE、增长机会 先算现金牛价值，再判断增长机会是否创造价值。
\(g=ROE\times b\) 留存收益带来增长 前提是新投入资本盈利能力与现有资产相同。
\(PE=\dfrac{P}{EPS}\)，\(\dfrac{1}{PE}=\dfrac{EPS}{P}\) 相对估值 / 倍数法 先确认 EPS 是 \(E_0\)、\(E_1\) 还是 TTM。

B. 高频判断

留存判断：\(ROE>r_s\) 时，留存创造价值；\(ROE=r_s\) 时，留存不改变价值；\(ROE0\)，留存都能提高利润增长率，但不一定提高股价。
PE 判断：增长机会是影响 PE 的最主要因素。PE 高通常对应成长型公司，PE 低通常对应价值型公司，但必须结合增长、风险、利率和会计口径一起判断。

C. 最容易错的地方

时点错：戈登公式用的是下一期股利 \(D_1\)，不是刚发的 \(D_0\)。两阶段模型中，终值 \(P_n\) 是站在第 \(n\) 年末看第 \(n+1\) 年开始的现金流。
口径错：历史 PE 用 \(E_0\)，预期 PE 用 \(E_1\)，TTM PE 用最近 4 个季度 EPS 之和。同一个公司 PE 不同，往往不是算错，而是分母口径不同。
结论错：股利支付率下降并不必然让股价下降，因为它同时提高留存比率 \(b\) 和增长率 \(g\)。最终看 \(ROE\) 是否高于 \(r_s\)。

D. 做题顺序

①
先圈出题目关键词：股利、盈利、留存、ROE、PE、未来价格、增长率。
②
再判断模型：股利用 DDM，盈利与留存用 NPVGO，倍数用 PE，未来价格用 DDM 递推。
③
最后检查时点：\(D_0/D_1\)、\(E_0/E_1\)、\(P_n\) 所在年份、终值是否需要再折现。

1单资产 · 收益的度量

① 历史收益率（"事后收益率"）

\( r = \dfrac{\text{利息（股利）收入} + \text{资本利得}}{\text{投入本金}} = \text{股利收益率} + \text{资本利得率} \)

单期分解：\( r_i = \dfrac{P_i - P_{i-1} + D_i}{P_{i-1}} \)（资本利得率 + 股利收益率）

【例】今年以每股 37 美元买入，明年以 40.33 美元卖出，期间分红 1.85 美元： \( r = \dfrac{1.85 + (40.33 - 37)}{37} = 14\% \)。

② 多期年化：算术 vs 几何

关键区别 = 是否考虑期间复利。

类型复利公式
算术平均收益率 否（单利） \( \bar r = \dfrac{r_1 + r_2 + \cdots + r_n}{n} \)
几何平均收益率 是（复合） \( (1+\bar r)^n = (1+r_1)(1+r_2)\cdots(1+r_n) \)
【例】两年收益率 8% 和 −4%：
算术：\( \bar r_A = \dfrac{8\% + (-4\%)}{2} = 2\% \)
几何：\( (1+\bar r_G)^2 = (1+8\%)(1-4\%) = 1.0368 \Rightarrow \bar r_G \approx 1.82\% \)
2% > 1.82% 算术 ≥ 几何，波动越大差距越大。

③ 算术与几何的关系（近似）

\( \bar r_A \approx \bar r_G + \dfrac{1}{2}\sigma^2 \)
串线：差额正比于方差 \( \sigma^2 \) —— 波动会"吃掉"复合收益。这是本章里收益与风险的第一次交汇。

④ 预期收益率（"期望/事前收益率"）

\( E(\tilde r) = \displaystyle\sum_{i=1}^{n} \pi_i \times r_i \)（\( \pi_i \) 为各情景概率）
【例】当前价 100，繁荣→120（½），衰退→100（½），不计利息： \( E(\tilde r) = \tfrac{1}{2}\times 20\% + \tfrac{1}{2}\times 0\% = 10\% \)。
思考：资产定价的折现率该用预期还是历史？
现实长期做法 —— 用历史收益率均值代替预期收益率（用历史预测未来）。所以两类收益率口径虽不同，但在估值实务中常被打通。

2单资产 · 风险的度量

① 历史风险（样本，分母 n−1）

方差：\( D(\tilde r) = \sigma^2(\tilde r) = \dfrac{1}{n-1}\displaystyle\sum_{i=1}^{n}\left(\tilde r_i - \bar r\right)^2 \)
标准差：\( SD(\tilde r) = \sigma(\tilde r) = \sqrt{\dfrac{1}{n-1}\displaystyle\sum_{i=1}^{n}\left(\tilde r_i - \bar r\right)^2} \)

分母用 n−1（样本无偏估计），不是 n。这是"历史/样本"视角的标志。

② 预期风险（概率加权）

方差：\( \sigma^2(\tilde r) = \displaystyle\sum_{i=1}^{n}\pi_i\left[r_i - E(\tilde r)\right]^2 \)
标准差：\( \sigma(\tilde r) = \sqrt{\displaystyle\sum_{i=1}^{n}\pi_i\left[r_i - E(\tilde r)\right]^2} \)
历史 ↔ 预期 对照：频率 \( \dfrac{1}{n-1} \) ↔ 概率 \( \pi_i \)；样本均值 \( \bar r \) ↔ 期望 \( E(\tilde r) \)。结构完全对称。

3资产组合 · 定义与期望收益率

A. 资产组合的定义

投资者财富在多种资产上的分配状况，用财富在不同资产上配置的比例 \( w_i \) 来刻画。

\( \tilde r_p = \displaystyle\sum_{i=1}^{n} w_i \times \tilde r_i ,\qquad \displaystyle\sum_{i=1}^{n} w_i = 1 \)

笔记：\( w_i \in (-\infty, +\infty) \)，可取负值（卖空）。

B. 组合的期望收益率（线性可加）

2 资产：\( E(\tilde r_p) = w_A E(\tilde r_A) + w_B E(\tilde r_B) \)
n 资产：\( E(\tilde r_p) = \displaystyle\sum_{i=1}^{n} w_i E(\tilde r_i) \)

推导（期望算子线性、常数可提）：

\( E\!\left(\displaystyle\sum_{i=1}^{n} w_i \tilde r_i\right) = \displaystyle\sum_{i=1}^{n} E(w_i \tilde r_i) = \displaystyle\sum_{i=1}^{n} w_i E(\tilde r_i) \)
一句话口诀：组合的期望 = 期望的组合。

4资产组合 · 方差与协方差

⚠ 经典错法：\( \sigma_p^2 \ne D(w_A\tilde r_A) + D(w_B\tilde r_B) \)。方差不是线性算子，必须保留 Cov 交叉项。

2 资产推导链（逐行展开）

\( \sigma_p^2 = D(\tilde r_p) = D(w_A\tilde r_A + w_B\tilde r_B) \)

5ρ 取值速记与边界公式

ρ解释组合标准差 \( \sigma_p \) 边界形态
\( \rho = 1 \)完全正相关\( \sigma_p = w_A \sigma_A + w_B \sigma_B \)（线性相加，无分散化）
\( 0 < \rho < 1 \)正相关通式 \( \sigma_p^2 = w_A^2\sigma_A^2 + w_B^2\sigma_B^2 + 2w_Aw_B\rho\sigma_A\sigma_B \)
\( \rho = 0 \)不相关\( \sigma_p^2 = w_A^2 \sigma_A^2 + w_B^2 \sigma_B^2 \)（交叉项消失）
\( -1 < \rho < 0 \)负相关通式
\( \rho = -1 \)完全负相关\( \sigma_p = \lvert w_A \sigma_A - w_B \sigma_B \rvert \)（可对冲为 0）
做题秒杀：看到 \( \rho = 1 \) 直接相加，看到 \( \rho = -1 \) 直接相减取绝对值。这两个边界式可以直接由通式代入 \( \rho = \pm 1 \) 推出。

8分散化效应（Diversification）

引例

【例】两只股票，期望收益都 5%，标准差都 10%，则它们构成的组合的期望收益和标准差是多少？

① 期望收益（与权重无关）：

\( E(r_p) = w_A \cdot 5\% + w_B \cdot 5\% = 5\% \)

② 标准差 —— 取决于 ρ：

\( \rho = 1 \)（完全正相关）\( \sigma_p = w_A \cdot 10\% + w_B \cdot 10\% = 10\% \)，没有分散化
\( \rho < 1 \)\( \sigma_p < 10\% \)，出现分散化收益

含义

当 \( \rho < 1 \) 时，组合的标准差 小于 构成组合的单个资产标准差的加权平均。
——"不要把所有鸡蛋都放在同一个篮子里"。
风险厌恶者愿意为分散化付出代价，因此分散化在金融市场上是"几乎免费的午餐"。

【思考】等权 1/n 组合方差公式

假设组合中共有 n 种资产，配置比例均为 \( 1/n \)，每种资产方差都是 \( \sigma^2 \)，任意两资产相关系数都是 \( \rho \)。求组合方差。

\( \boxed{\;\sigma_p^2 = \rho \sigma^2 + \dfrac{(1-\rho)\sigma^2}{n}\;} \)

逐项收敛（笔记列举）：

n\( \dfrac{(1-\rho)\sigma^2}{n} \)组合方差 \( \sigma_p^2 \)
1\( (1-\rho)\sigma^2 \)\( \sigma^2 \)（退化为单资产）
2\( \tfrac{1}{2}(1-\rho)\sigma^2 \)\( \rho\sigma^2 + \tfrac{1}{2}(1-\rho)\sigma^2 \)
3\( \tfrac{1}{3}(1-\rho)\sigma^2 \)持续下降
4\( \tfrac{1}{4}(1-\rho)\sigma^2 \)持续下降

性质：随 n 增加，组合方差持续下降，但下降速度边际递减。第二项 \( (1-\rho)\sigma^2/n \) 是可被分散掉的部分，第一项 \( \rho\sigma^2 \) 是无论怎么加都"赶不走"的部分。

\(\sigma_p^2 \sim n\) 示意

9资产组合的风险二分

总风险 = 系统性风险 + 非系统性风险
类型别名来源能否分散例子
系统性风险 市场风险 能同时影响大量资产收益的风险，由宏观因素引起 不可分散 货币政策、利率变动、汇率、宏观经济周期
非系统性风险 公司特有风险 / 特质性风险 只影响某种特定资产，与个别公司相联系 可分散 研发失败、财务造假、行业突发事件
核心串线：分散化能消除的是非系统性风险，但永远消除不了系统性风险。这就是为什么 \( \sigma_p^2 \) 极限会落在 \( \rho\sigma^2 \) 而不是 0。

0现代资产组合理论（MPT）的前提与效用函数

A. 前提假定

①
证券收益率是满足正态分布的随机变量，并且投资者效用函数是二次型。
②
投资者期望获得最大收益，但不喜欢风险，是风险厌恶者。
③
构建组合的依据：在既定收益水平下，使风险最小；或者在既定风险水平下，使收益最大。
④
以期望收益率（历史收益率均值）衡量投资者收益，以收益率方差（或标准差）衡量资产风险，两者共同影响投资者效用。
概念区分：正态分布描述的是收益率这个随机变量的分布形态；二次型描述的是效用函数里包含风险的平方惩罚项。两者不是一个意思。

B. 效用函数

\( U = E(r_p) - \dfrac{1}{2}A\sigma_p^2 \)
符号含义
\(E(r_p)\)组合期望收益率，是效用的正向来源。
\(\sigma_p^2\)组合收益率方差，是风险惩罚项。
\(A\)风险厌恶系数。\(A>0\) 为风险厌恶，\(A=0\) 为风险中性，\(A<0\) 为风险偏好。
读公式：收益越高，效用越高；风险越高，效用越低。\(A\) 越大，同样的 \(\sigma_p^2\) 会带来更大的效用损失。

C. 无差异曲线

定义：无差异曲线是给消费者（投资者）带来相同效用的组合所构成的曲线。

由效用函数变形：

\( E(r_p)=U+\dfrac{1}{2}A\sigma_p^2 \quad (A>0) \)

横轴为组合标准差 \(\sigma_p\)，纵轴为组合期望收益率 \(E(r_p)\)。在同一条曲线上，效用 \(U\) 不变；风险越高，必须有更高的期望收益补偿。更靠上的曲线代表更高效用。

10一种风险资产和一种无风险资产的组合

A. 风险资产 vs 无风险资产

类型定义收益率记号
风险资产 不同状态下有不同实际收益，收益率存在不确定性，是随机变量。 \(\tilde r_s\)
无风险资产 任何状态下都有相同实际收益，收益率是常数。 \(r_f\)
\(E(r_f)=r_f,\qquad \sigma_f^2=0,\qquad \sigma_f=0\)

B. 组合收益率与标准差

设风险资产占比为 \(w\)，无风险资产占比为 \(1-w\)：

\(\tilde r_p=w\tilde r_s+(1-w)r_f\)

组合期望收益率：

\(E(\tilde r_p)=wE(\tilde r_s)+(1-w)r_f = r_f+w\left[E(\tilde r_s)-r_f\right]\)

组合标准差：

\(\sigma_p=w\sigma_s\)
无风险资产的标准差为 0，且与风险资产的协方差为 0，所以组合风险只来自风险资产头寸。若允许卖空或借贷，更完整地看是 \(\sigma_p=|w|\sigma_s\)。

C. 资本配置线与夏普比率

由 \(\sigma_p=w\sigma_s\) 得 \(w=\sigma_p/\sigma_s\)，代回期望收益公式：

\(E(\tilde r_p)=r_f+\dfrac{E(\tilde r_s)-r_f}{\sigma_s}\sigma_p\)

这是一条以 \(r_f\) 为截距、以夏普比率为斜率的直线。

\(\text{Sharpe Ratio}=\dfrac{E(\tilde r_s)-r_f}{\sigma_s}\)
夏普比率：资产为单位风险所补偿的风险溢价，也就是单位总风险对应的超额收益。常用于基金业绩评价。
\(\text{Risk Premium}=E(\tilde r_s)-r_f\)

D. 权重区间与杠杆

权重投资含义
\(w=0\)全部持有无风险资产。
\(0<w<1\)风险资产和无风险资产混合。
\(w=1\)全部持有风险资产。
\(w>1\)借入资金投资风险资产，\(1-w<0\) 表示无风险资产头寸为负。

E. 最优风险资产权重

引入效用函数后，最优权重来自最大化 \(U=E(r_p)-\frac{1}{2}A\sigma_p^2\)：

\(w^*=\dfrac{E(\tilde r_s)-r_f}{A\sigma_s^2}\)
\(E(\tilde r_p)=r_f+\dfrac{\left[E(\tilde r_s)-r_f\right]^2}{A\sigma_s^2}, \qquad \sigma_p=\dfrac{E(\tilde r_s)-r_f}{A\sigma_s}\)

F. 典型考法：夏普比率与杠杆

1 夏普比率 2025 · 华东理工

题干：一只股票年化标准差为 80%，年化期望收益率 6%，市场无风险利率 2%，求夏普比率。

\(\text{Sharpe}=\dfrac{6\%-2\%}{80\%}=0.05\)

答案：0.05

2 借款投资股票 2022 · 清华

题干：投资者手头有 1000 万，按 5% 利率借入 4000 万，全部投资于股票。股票期望收益率 6%，波动率 20%，求投资组合的期望收益率和波动率。

①
风险资产投入为 5000 万，自有资金为 1000 万，所以 \(w=\frac{5000}{1000}=5\)，无风险资产权重 \(1-w=-4\)。
②
期望收益率：\(E(r_p)=5\times6\%-4\times5\%=10\%\)。
③
波动率：\(\sigma_p=5\times20\%=100\%\)。

答案：收益率 10% 波动率 100%

杠杆题关键：权重按自有资金计算，不按总资产计算。借款投资时 \(w\) 可以大于 1，无风险资产权重 \(1-w\) 为负。

11资产配置的意义 · 通向后续两条主线

笔记最后留了一行重要总结：资产配置（组合理论）的意义，可以从两个方面来看。

① 风险管理
通过对冲、衍生品、跨资产/跨市场配置来降低组合中的非系统性风险，并用衍生工具应对剩下的系统性风险。
关键词：对冲、期货、期权、互换、风险预算
② 资产定价
既然非系统性风险可以通过分散化消除，那么资本市场只为系统性风险"支付"风险溢价。这一思想直接通向 CAPM（\( \beta \) 度量系统性风险）和 APT（多因子定价）。
关键词：β 系数、风险溢价、市场组合、因子模型
一句话收口：现代资产组合理论（MPT）是后续所有"风险与定价"内容的地基 —— 风险管理在做"分散与对冲"，资产定价在做"为剩下的系统性风险定价"。
