# 纠错经验记录

这个文件只记录做学习笔记页面时已经踩过的坑，目的是避免同样的小错误反复出现。

## 学习优先级

- 页面调整必须服务于理解、复习、做题正确率和考试得分。
- 不为了部署、域名、动效、工具配置、无关优化消耗注意力。
- 如果一个修改不能明显提高学习效率，先停下来回到知识结构、题目训练和错题复盘。

## 页面与内容

- `chapters/` 里的独立章节页要和 `index.html` 中对应章节内容保持一致。
- 如果首页和章节页拆分，先确认知识点覆盖，再改样式。
- 第二章债券估值目前仍是占位内容，不要误判为已完成。

## 视觉规则

- 表格可以保留横线，因为它承担对齐和比较功能。
- 正文尽量少用横线，章节层级优先靠字号、留白、字重、颜色和浅色块表达。
- 打印预览尤其要避免标题线、题块分割线、例题框上下线过多，否则阅读会很累。
- 不要为了“设计感”牺牲密度和可复习性；公司理财笔记应该清楚、克制、便于扫读。

## 公式与图示

- 大段知识结构不要用字符画 `pre` 硬排，优先用 HTML 层级结构和 MathJax 公式。
- SVG 里的公式标注不要交给 MathJax 渲染，容易出现字号异常。
- 图注里的短公式如果曾经渲染异常，优先用普通 HTML 上标，例如 `&rho;&sigma;<sup>2</sup>`。
- 图示的目标是帮忙理解关系，不要做得过大、过抢眼或压过正文。

## 导航

- `chapters/index.html` 是章节入口，只需要帮助快速进入学习页面。
- 导航页保持简单：章节名、状态、入口链接即可，不需要做成展示页。

## 操作纪律

- 用户说“先不要改代码，只阅读”时，只能阅读和汇报。
- 用户指出视觉问题时，先定位具体 CSS/HTML 原因，再做小范围修正。
- 修改后优先检查是否影响四个章节页的一致性。
