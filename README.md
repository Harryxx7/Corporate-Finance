# 纠错经验记录

这个文件只记录做学习笔记页面时已经踩过的坑，目的是避免同样的小错误反复出现。

## 学习优先级

- 页面调整必须服务于理解、复习、做题正确率和考试得分。
- 不为了部署、域名、动效、工具配置、无关优化消耗注意力。
- 如果一个修改不能明显提高学习效率，先停下来回到知识结构、题目训练和错题复盘。

## 页面与内容

- 新增学习内容只追加或维护 `chapters/` 里的章节 HTML。
- 章节外的 `index.html` 不再作为内容同步目标，除非用户明确要求改首页。
- 如果首页和章节页内容不一致，以 `chapters/` 里的独立章节页为准。
- 第二章债券估值目前仍是占位内容，不要误判为已完成。

## 视觉规则

- 表格可以保留横线，因为它承担对齐和比较功能。
- 正文尽量少用横线，章节层级优先靠字号、留白、字重、颜色和浅色块表达。
- **无边框极简美学排版标准 (Borderless Standard) [硬性限制]**：全书（包含一、二、三、四章）在任何屏幕显示、打印预览及实际打印（彩色/黑白）的样式中，严禁对 `.qblock`（问题块）、`.hint/.score-box`（提示/考点分值框）、`.mistake-box`（易错框）以及 `.eq`（公式块）等内容块添加任何左侧纵向细边框（`border-left` 一律置零），并严禁添加左侧内边距（`padding-left` 一律置零），确保所有内容块文字在左侧呈现绝对、完美、整齐的单一直线对齐，严防版面因细线框过多显得繁复杂乱。
- **PDF 导出打印悬浮条隐藏限制 [硬性限制]**：在打印媒体查询（`@media print`）样式中，必须使用高权重特异性（Specificity）选择器 `body.print-preview .preview-bar`、`body.printing .preview-bar` 以及 `.topbar, .sidenav, .preview-bar` 彻底将打印预览控制栏隐藏（`display: none !important;`），以完全杜绝跨页公式被悬浮栏遮挡截断的排版 Bug。
- 打印预览尤其要避免标题线、题块分割线、例题框上下线过多，否则阅读会很累。
- 黑白打印版本（print-bw）必须作为彩色打印版本（print-color）的完美黑白拷贝：保持完全一致的布局结构和缩进间距，绝不能在黑白版中使用背景灰色填充色块或加粗竖线（实现0色块、透明底、极细灰色线），确保两者在切换打印模式时排版100%重合且足够清爽。
- 不要为了“设计感”牺牲密度和可复习性；公司理财笔记应该清楚、克制、便于扫读。

## 公式与图示

- 大段知识结构不要用字符画 `pre` 硬排，优先用 HTML 层级结构和 MathJax 公式。
- SVG 里的公式标注不要交给 MathJax 渲染，容易出现字号异常。
- 图注里的短公式如果曾经渲染异常，优先用普通 HTML 上标，例如 `&rho;&sigma;<sup>2</sup>`。
- 图示的目标是帮忙理解关系，不要做得过大、过抢眼或压过正文。
- 时间轴用于考试分析时，优先画成固定坐标 SVG；只标时点、关键现金流和阶段，不把大段解释塞进图里。
- 时间轴 SVG 的 CSS 必须只作用于直接子级，例如 `.exam-timeline > svg`，不要误伤 MathJax 自动生成的公式 SVG。

## 导航

- `chapters/index.html` 是章节入口，只需要帮助快速进入学习页面。
- 导航页保持简单：章节名、状态、入口链接即可，不需要做成展示页。

## 操作纪律

- 用户说“先不要改代码，只阅读”时，只能阅读和汇报。
- 用户指出视觉问题时，先定位具体 CSS/HTML 原因，再做小范围修正。
- 修改后优先检查是否影响四个章节页的一致性。
